[[what are some examples of business logic vulnerabilities]]

- assumption that the end user only uses the conventional way to access the application via the web browser.
- it is a dangerous assumption because of trusting that the client side validation will protect against the end user offering malicious input, an attacker can basically use for instance burp proxy/caido proxy to intercept the request before it gets to the server side logic rendering the client-side control useless.
- learn to first go through the application to understand it's workflow.
